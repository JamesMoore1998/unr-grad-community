# License: not yet chosen

This repository does not currently include a `LICENSE` file. No license has been selected on
the repository owner's behalf — that's a decision only they can make (it affects what others
are legally allowed to do with this code and content).

Common options for a project like this:

- **MIT** — permissive, simple, widely used for small web projects.
- **CC BY 4.0** — often used for content-heavy sites rather than code.
- **CC0 / public domain dedication** — for a community resource with no attribution requirement.
- Keeping the repository **unlicensed** (default all-rights-reserved) if it's meant to stay
  private/internal.

Once a license is chosen, add a `LICENSE` file at the repository root with the standard license
text, update this file (or delete it), and remove the corresponding note from `README.md`.
